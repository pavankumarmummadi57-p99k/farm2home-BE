# Farm2Home Backend

Spring Boot based backend for a local farmer marketplace application.

## Features
- JWT Authentication
- Role Based Security (Admin, Farmer, Customer)
- Farmer Verification
- Category Management
- Product CRUD
- Product Image Upload
- Get My Products
- Product Details API

## Tech Stack
- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Maven

## Status
Product module completed successfully.
